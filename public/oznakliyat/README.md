# Özin Nakliyat demo görselleri

Bu klasöre firmanın gerçek fotoğraflarını şu isimlerle koy:

- `ozin-1.jpg` → Balonlu naylonla sarılı eşyalar (EN GÜÇLÜSÜ — hero arka planı + galeride büyük kare)
- `ozin-2.jpg` → Ekip / çalışan
- `ozin-3.jpg` → Deniz manzaralı daire / taşınma
- `ozin-4.jpg` → Kırmızı kazaklı gülen çalışan

Notlar:
- Yatay (landscape) foto tercih et, en az ~1200px genişlik.
- `.jpg` uzantısı olacak. `.jpeg`/`.png` koyarsan `app/oznakliyat/OznakliyatClient.tsx` içindeki uzantıları güncelle.
- Fotoğraf yoksa sayfa çökmüyor; boş kutular placeholder gösteriyor.
